# References & Prior Art

- **[osm2streets](https://github.com/a-b-street/osm2streets)**: Inspiration for street cross-section geometry, lane layouts, and intersection modeling.
- **[Overture Maps Foundation](https://overturemaps.org/)**: Open map data schemas and GeoParquet distributions.
- **[OpenStreetMap](https://www.openstreetmap.org/)**: Global open geographic database and Overpass API.
- **[MapLibre GL JS](https://maplibre.org/)**: Open-source client-side vector and raster map renderer.
- **[DuckDB-WASM](https://duckdb.org/docs/api/wasm/overview)**: In-browser analytical SQL engine with spatial and HTTPFS extensions.
